# 🏪 Supermarket Checkout Simulation

A discrete-event simulation project developed to analyze and improve supermarket checkout operations using Arena Simulation.

> 🎓 **Academic Team Project**  
> Developed as part of an Industrial Engineering course.

---

# 📌 Project Overview

This project models the checkout process of a supermarket using Arena Simulation. The objective is to evaluate the current system performance, identify bottlenecks, and compare improvement scenarios to reduce customer waiting times and increase operational efficiency.

---

# 🎯 Objectives

- Model supermarket checkout operations.
- Analyze customer flow and queue behavior.
- Evaluate system performance.
- Compare alternative improvement scenarios.
- Support operational decision-making using simulation.

---

# 🛠 Tools & Methods

- Arena Simulation
- Discrete-Event Simulation
- Queue Analysis
- Statistical Analysis
- Performance Evaluation
- Scenario Comparison

---

# 📈 Key Results

- Simulated customer arrivals and checkout operations.
- Evaluated queue lengths and waiting times.
- Compared different operational scenarios.
- Identified opportunities to improve service efficiency.
- Supported decision-making through simulation results.
